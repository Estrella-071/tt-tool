# 봄맞이 청소 도우미(Windows 베타)

[English](README-SWEEP.md) · [繁體中文](README-SWEEP.zh-TW.md) · [日本語](README-SWEEP.ja.md) · 한국어

Python, ADB 또는 FFmpeg를 설치하지 않고도 `SweepAssistant.exe`를 두 번 클릭하여 실행합니다. 프로그램에는 이러한 실행 도구가 포함되어 있습니다. 처음 시작되면 ADB는 백그라운드 서비스에서 사용할 수 있도록 로컬 사용자 폴더에 자동으로 배치됩니다. Windows 컴퓨터는 64비트여야 하며 처음 시작할 때 프로그램의 압축을 푸는 데 시간이 걸립니다.

1. "모바일 ADB" 또는 "컴퓨터 창"을 선택하고 "재감지"를 클릭한 후 소스를 선택하십시오.
2. 휴대폰 모드에서는 Android에서 USB 디버깅을 활성화하고 데이터 케이블을 연결한 다음 휴대폰에서 컴퓨터를 허용해야 합니다. 다른 컴퓨터에는 휴대폰 제조업체의 USB 드라이버가 필요할 수 있습니다. 연결 후 즉시 미리보기가 표시됩니다. 일반 청소 준비 화면에 들어간 후 프로그램은 자동으로 확률 정보를 두 번 켜거나 끄고 지연을 측정하며 성공한 후에만 시작할 수 있습니다. 프로그램은 다음 교정을 위해 휴대전화의 측정된 지연 편차를 로컬로 저장합니다. 공유 패키지와 함께 전송되지 않습니다.
3. 창 모드는 기본적으로 공백을 사용합니다. 에뮬레이터의 키 설정에서 게임의 시작/중지 위치에 공백을 매핑하세요. 자동 클릭이나 F1~F12를 선택할 수도 있습니다. 준비 화면에 들어가서 게임 창으로 전환하면 프로그램이 확률 정보 자동 보정을 켜거나 끕니다. 시작한 후 3초 이내에 게임 창으로 다시 전환하여 전경에 계속 표시되도록 합니다.
4. 청소 준비 화면에서 게임이 정지된 후 '라운드 시작'을 클릭하세요. 게임에 표시된 소품 하나가 소모됩니다. 프로그램은 노란색 영역에 도달하려고 시도합니다. 라운드가 끝나면 멈추고 확대 다이얼은 게임에서 처리됩니다. 프로그램은 정지 화면을 사용하여 노란색으로 두 번 떨어지는지 여부를 추정합니다. 표시되는 내용은 화면 해석이므로 경계선 부근에 오류가 있을 수 있습니다.

인식은 화면 너비 하단에 맞춰 정렬되어 다양한 종횡비의 완전한 수직 게임 화면을 지원합니다. 게임 화면 차단, 검은색 테두리 또는 자르기 방지 창 상단의 도구 모음은 하단 제어 영역의 인식에 영향을 미치지 않습니다. 다양한 장치와 게임 레이아웃은 여전히 ​​테스트하고 확인해야 합니다. 취소하려면 "중지"를 누르십시오. 전화기의 전경이 불분명하거나 창의 초점이 맞지 않거나 화면이 오래되었거나 확인할 수 없는 경우 새 입력이 전송되지 않습니다.

이 버전은 실험적인 버전입니다. 실제 휴대폰 테스트에서는 노란색이 2번 맞았고, 누락된 부분도 있었습니다. 지연과 영상 속도는 변동될 수 있으며 매번 적중을 보장할 수는 없습니다. 다양한 휴대폰은 자체 교정 데이터를 축적해야 합니다. 창 캡처 및 공간 단축키는 LDPlayer에서 테스트되었으며 노란색 판정이 두 번 완료되었으며 누락도 있었습니다. 다른 시뮬레이터 및 기타 단축키는 아직 테스트되지 않았습니다. 다양한 해상도, 화면 비율, 게임 버전, 기기 지연 또는 속도가 결과에 영향을 미칠 수 있으므로 관찰하면서 사용하시기 바랍니다.

소스 코드 및 타사 라이센스 정보는 배포 패키지에 포함되어 있습니다.
