# 本地資料與公開發布

[English](PRIVACY.md) · 繁體中文 · [日本語](PRIVACY.ja.md) · [한국어](PRIVACY.ko.md)

目前的 Windows 安裝版將設定、校準與本機日誌保存在 %LOCALAPPDATA%\tt-tool\data。解除安裝時預設保留，可選擇清除。

畫面辨識在本機處理。手動檢查更新或下載更新時，程式會連線 GitHub。診斷資料不會自動上傳。執行程式不需要註冊、帳號密碼或 API 金鑰。

正常釣魚不會自動儲存截圖、軌跡、運行日誌或診斷ZIP。暫停、F9和關閉不會匯出測試資料。歷史診斷工具和迴歸程式碼僅用於開發，不由本發行版的正常運作路徑啟動。

遺跡探險在首領做出決定或長時間等待時，會在本機 `logs/ruins_decisions.jsonl` 記錄勝率讀值、是否辨識到紅寶、決策與輸入結果，供排查卡住原因。記錄不包含截圖、帳號或裝置識別碼，約 256 KB 輪換一次，最多保留目前及前一份；不會自動上傳。

| 位置 | 內容 | 公開原始碼包 |
|---|---|---|
| `config.example.json` | 預設設置，框選為空 | 包含 |
| `assets/templates/` | 必要的局部控制圖 | 包含 |
| `docs/images/` | 脫敏操作範例 | 包含 |
| `tests/assets/` | 只包含判定條、重量圖示及收下按鈕的局部迴歸素材 | 內含 |
| `config.json` | 本機設定、模擬器種類、視窗標題與框選 | 排除 |
| `speed_profile.json` | 明確完成校準後的比例與統計量 | 排除 |
| `snapshots/`、`recordings/` | 用戶主動截圖/錄製的文件，可能包含暱稱或聊天 | 排除 |
| `logs/`、`support/`、`replay_output/` | 啟動異常、遺跡首領決策或手動開發工具輸出 | 排除 |
| `trial_records/`、`trial_exports/` | 歷史測試建構的資料目錄 | 排除 |

源碼版預設把本機檔案保存在工程目錄，便攜啟動入口使用`data/`。啟動器僅在異常時保存本機錯誤訊息，可能包含安裝路徑；不要原樣公開。固定速度運轉不保存原始位置樣本；明確校準只把合格的比例、樣本數和離散度寫入速度檔。

`.gitignore` 無法刪除已提交的 Git 歷史。公開更新時執行 `python build_release.py`，該入口使用明確的檔案清單，不掃描額外的本機資料。請勿直接壓縮使用過的整個專案目錄，也不要將歷史診斷 ZIP 提交到儲存庫。

`make_support_bundle.py`是手動開發工具，預設只含公開原始碼。附加截圖、錄影或日誌需明確參數；可能包含個人訊息，分享前逐項檢查。問題回饋優先提供版本、狀態提示和重複步驟，不公開帳號密碼、聊天記錄、私人目錄或完整本機設定。
