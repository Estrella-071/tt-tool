# ローカルデータと公開

[English](PRIVACY.md) · [繁體中文](PRIVACY.zh-TW.md) · 日本語 · [한국어](PRIVACY.ko.md)

現在の Windows インストール版は、設定、調整値、ローカルログを %LOCALAPPDATA%\tt-tool\data に保存します。アンインストール時は既定で保持され、削除も選択できます。

画面認識は端末上で処理されます。更新を手動で確認またはダウンロードするとき、アプリは GitHub に接続します。診断データは自動アップロードされません。実行に登録、アカウントのパスワード、API キーは必要ありません。

通常のフィッシングでは、スクリーンショット、トラック、実行ログ、診断 ZIP は自動的に保存されません。一時停止、F9、シャットダウンではテスト データはエクスポートされません。履歴診断ツールと回帰コードは開発のみを目的としており、このリリースの通常のランタイム パスからは起動されません。

遺跡探検でボスへの対応を決めたときや長時間待機したとき、勝率の読取値、赤い宝物の認識、判断および入力結果を `logs/ruins_decisions.jsonl` に記録します。停止の原因を調べるための記録で、スクリーンショット、アカウント、端末識別子は含みません。約 256 KB でローテーションし、現在と直前のファイルを保持します。自動アップロードは行いません。

|場所 |コンテンツ |オープンソース パッケージ |
|---|---|---|
| `config.example.json` |デフォルト設定、ボックス選択は空です |含まれています |
| `assets/templates/` |必要なローカル制御図 |含まれています |
| `docs/images/` |減感作動作例 |含まれています |
| `tests/assets/` |判定バー、重量アイコン、承認ボタンのみを含む部分回帰素材 |含まれています |
| `config.json` |ローカル設定、シミュレータの種類、ウィンドウのタイトルとボックスの選択 |除外 |
| `speed_profile.json` |キャリブレーション後の比率と統計を明確にする |除外 |
| `snapshots/`、`recordings/` | ユーザーが撮影した画像や録画。ニックネームやチャットを含む場合があります | 除外 |
| `logs/`、`support/`、`replay_output/` |起動エラー、遺跡のボス判断、手動開発ツールの出力 |除外 |
| `trial_records/`、`trial_exports/` |履歴テストによって構築されたデータ ディレクトリ |除外 |

ソース コード バージョンでは、デフォルトでローカル ファイルがプロジェクト ディレクトリに保存され、ポータブル スタートアップ エントランスは `data/` を使用します。ランチャーは、例外が発生した場合にのみ、インストール パスを含むローカル エラー情報を保存します。そのまま公開しないでください。固定速度の実行では、生の位置サンプルは保存されません。明示的なキャリブレーションでは、適切なスケール、サンプル数、および分散のみが速度ファイルに書き込まれます。

`.gitignore` コミットされた Git 履歴を削除できません。パブリック更新では、明示的なファイル リストを使用し、追加のローカル データをスキャンしない `python build_release.py` を実行する必要があります。使用するプロジェクト ディレクトリ全体を直接圧縮したり、履歴診断 ZIP をウェアハウスに送信したりしないでください。

`make_support_bundle.py` は、デフォルトでオープン ソース コードのみを含む手動開発ツールです。スクリーンショット、ビデオ、またはログを添付するには、明示的なパラメータが必要です。個人情報が含まれる場合がありますので、共有する前に各項目を確認してください。問題に関するフィードバックでは、バージョン、ステータス プロンプト、および再現手順の提供が優先されます。アカウントのパスワード、チャット記録、プライベート ディレクトリ、または完全なローカル構成は公開されません。
