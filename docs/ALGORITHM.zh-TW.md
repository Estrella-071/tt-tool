# 黃條點擊時序

[English](ALGORITHM.md) · 繁體中文 · [日本語](ALGORITHM.ja.md) · [한국어](ALGORITHM.ko.md)

> 此技術文件包含歷史版本與測量紀錄。目前的安裝方式和支援功能請見[主要指南](../README.zh-TW.md)。

截圖和按鍵使用兩個獨立期限：截圖預設間隔100毫秒；一個待執行按鍵由控制循環單獨檢查，不等待下一次截圖。控制循環通常每10毫秒讓出線程，臨近按鍵期限時按剩餘時間等待。實際喚醒精確度仍取決於Windows調度。

## 往返運動

以軌道可見外框寬度為1，預設速度為每秒0.606條寬。魚漂中心的左右端點採用同一座標系的0.083和0.940，避免把軌道裝飾當成中心行程；單程約1.41秒。歸一化後的影像僅用於控制定位，速度不依賴原始螢幕解析度。

運動相位始終向前增加，位置由三角波映射到軌道。到達端點只反轉方向，不重置速度。首次識別預設向右，之後根據時間自動跨越端點。新截圖將位置投到最接近預測的往返分支，避免僅憑兩張圖的位移符號猜方向。多輪黃條繼續使用同一運動相位。

## 點選規則

- 將觀測位置預測到輸入生效時刻；屆時仍在黃色範圍內才立即點擊，否則預約下一次經過。
- 尚未進入：計算下一次經過黃條中部的時間，扣除輸入延遲後預約點擊。左右兩個方向和需要先折返的路徑都參與計算。
- 黃條很窄時仍計算中部，不因固定像素邊距大於條寬而禁止點擊。
- 一個待執行計劃會被下一張圖更新；未知畫面、其他階段、暫停、失焦或視窗尺寸變更取消計劃。
- 同一趟經過最多點擊一次；黃條變化可進入下一輪。黃條未變時，離開後下一次經過可以重試，不依賴永久鎖定或有限重試次數。
- 魚漂遮擋黃色時保留已確認的完整邊界，避免把剩餘一小段顏色當成新目標。

按鍵臨近時優先處理輸入，再進行截圖。所有計劃均保留目前視窗和緊急暫停檢查，不使用長時間不可取消的休眠。過了整段命中窗口則重新計算下一次經過。

## 速度與延遲

固定速度從本機校準檔案讀取，未儲存過時用參考值。明確勾選校準後，只利用正常取樣中的同向區間；高頻時保留區間起點，累計至少0.25秒再估速，按鍵或折返後重新取區間；排除跨端點、輸入動效附近、零位移和明顯異常速度，以中位數與MAD篩選離群值。雙向樣本穩定後保存比例、樣本數和離散度，停止校準；不保存原始軌跡，不額外加密截圖。

游戲響應延遲基準默認40毫秒，可手動調整。本機補償只測量計畫時刻到系統輸入執行的可測部分，單次調整和總補償都有上限；它不等於遊戲內部接收時刻，也不會憑畫面變化宣稱測得完整遊戲延遲。

## 適用邊界

此策略假設兩次截圖之間近似勻速運動，首次方向向右。低頻截圖可能錯過短暫上鉤提示，也不能同時確定任意方向、任意速度和任意停頓；在黃條中途重新啟動時，首個方向可能與實際相反。建議在準備下鉤時啟動。遊戲暫停、明顯變速、系統長時間阻塞或視覺漏檢仍可能導致漏按/誤按。

目前不使用停幀偵測去阻止已預約輸入。影像辨識仍要求完整框選且遊戲佈局能對應模板；改變寬高比造成控制重新排版時需要重新適配，比例速度不能取代視覺適配。

運行時不自動儲存截圖、軌跡、日誌或診斷套件。僅手動截圖/錄製及明確勾選校準會寫入對應本機檔案。
