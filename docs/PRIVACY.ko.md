# 로컬 데이터 및 공개 릴리스

[English](PRIVACY.md) · [繁體中文](PRIVACY.zh-TW.md) · [日本語](PRIVACY.ja.md) · 한국어

현재 Windows 설치 버전은 설정, 보정 및 로컬 로그를 %LOCALAPPDATA%\tt-tool\data에 저장합니다. 제거 시 기본적으로 유지되며 삭제할 수도 있습니다.

화면 인식은 컴퓨터에서 처리됩니다. 업데이트를 수동으로 확인하거나 다운로드할 때 앱이 GitHub에 연결됩니다. 진단 데이터는 자동으로 업로드되지 않습니다. 프로그램 실행에 가입, 계정 비밀번호 또는 API 키는 필요하지 않습니다.

일반 낚시에서는 스크린샷, 트랙, 러닝 로그 또는 진단 ZIP이 자동으로 저장되지 않습니다. 일시 중지, F9 및 종료는 테스트 데이터를 내보내지 않습니다. 기록 진단 도구 및 회귀 코드는 개발 목적으로만 사용되며 이 릴리스의 일반 런타임 경로에서는 실행되지 않습니다.

유적 탐험에서 보스 대응을 결정하거나 오래 기다릴 때 승률 판독값, 빨간 보물 인식 여부, 결정과 입력 결과를 `logs/ruins_decisions.jsonl`에 기록합니다. 멈춤 원인을 확인하기 위한 기록이며 스크린샷, 계정, 기기 식별자는 포함하지 않습니다. 약 256 KB마다 순환하며 현재 파일과 이전 파일을 보관합니다. 자동 업로드되지 않습니다.

| 위치 | 내용 | 오픈 소스 패키지 |
|---|---|---|
| `config.example.json` | 기본 설정, 상자 선택이 비어 있음 | 포함 |
| `assets/templates/` | 필요한 로컬 제어 다이어그램 | 포함 |
| `docs/images/` | 둔감화 동작 예 | 포함 |
| `tests/assets/` | 판단바, 가중치 아이콘, 승인 버튼만 포함된 부분 회귀 자료 | 포함 |
| `config.json` | 로컬 설정, 시뮬레이터 유형, 창 제목 및 상자 선택 | 제외 |
| `speed_profile.json` | 교정 후 비율과 통계를 명확히 합니다 | 제외 |
| `snapshots/`, `recordings/` | 사용자가 촬영한 스크린샷/녹화 파일(닉네임이나 채팅이 포함될 수 있음) | 제외 |
| `logs/`, `support/`, `replay_output/` | 시작 오류, 유적 보스 결정 또는 수동 개발 도구 출력 | 제외 |
| `trial_records/`, `trial_exports/` | 기록 테스트를 통해 구축된 데이터 디렉토리 | 제외 |

소스코드 버전은 기본적으로 프로젝트 디렉터리에 로컬 파일을 저장하고, 포터블 스타트업 입구는 `data/`를 사용한다. 실행 프로그램은 예외가 있는 경우에만 로컬 오류 정보를 저장합니다. 여기에는 설치 경로가 포함될 수 있습니다. 있는 그대로 공개하지 마세요. 고정 속도 실행은 원시 위치 샘플을 저장하지 않습니다. 명시적 교정은 검증된 스케일, 샘플 수 및 분산만 속도 파일에 기록합니다.

`.gitignore` 커밋된 Git 기록을 삭제할 수 없습니다. 공개 업데이트는 명시적 파일 목록을 사용하고 추가 로컬 데이터를 검색하지 않는 `python build_release.py`를 실행해야 합니다. 사용된 전체 프로젝트 디렉터리를 직접 압축하지 말고, 기록 진단 ZIP을 창고에 제출하지 마세요.

`make_support_bundle.py`는 기본적으로 오픈 소스 코드만 포함된 수동 개발 도구입니다. 스크린샷, 비디오 또는 로그를 첨부하려면 명시적인 매개변수가 필요합니다. 개인정보가 포함될 수 있으므로 공유하기 전에 각 항목을 확인하세요. 문제 피드백은 버전, 상태 프롬프트 및 재생 단계 제공에 우선순위를 둡니다. 계정 비밀번호, 채팅 기록, 개인 디렉터리 또는 전체 로컬 구성은 공개되지 않습니다.
