# 春のクリーニング アシスタント (Windows ベータ版)

[English](README-SWEEP.md) · [繁體中文](README-SWEEP.zh-TW.md) · 日本語 · [한국어](README-SWEEP.ko.md)

`SweepAssistant.exe` をダブルクリックすると、Python、ADB、または FFmpeg をインストールすることなく実行できます。プログラムにはこれらの実行ツールが含まれています。初めて起動すると、ADB はバックグラウンド サービスで使用できるようにローカル ユーザー フォルダーに自動的に配置されます。 Windows コンピューターは 64 ビットである必要があり、最初の起動時にプログラムを解凍するのに時間がかかります。

1. 「モバイル ADB」または「コンピュータ ウィンドウ」を選択し、「再検出」をクリックしてソースを選択します。
2. 携帯電話モードでは、Android で USB デバッグを有効にし、データ ケーブルを接続して、電話でコンピュータを許可する必要があります。コンピュータによっては、携帯電話メーカーの USB ドライバが必要な場合があります。接続直後にプレビューが表示されます。一般清掃準備画面に入った後、プログラムは遅延を測定するために確率情報のオンとオフを 2 回自動的に切り替え、成功した場合にのみ開始できます。プログラムは、携帯電話の測定された遅延偏差を次回の校正のためにローカルに保存します。共有パッケージでは転送されません。
3. ウィンドウ モードでは、デフォルトでスペースが使用されます。エミュレータのキー設定でゲームの開始/停止位置にスペースをマッピングしてください。自動クリックまたは F1 ～ F12 を選択することもできます。準備画面に入り、ゲームウィンドウに切り替えると、プログラムは確率情報の自動調整をオンまたはオフにします。開始後、3 秒以内にゲーム ウィンドウに戻り、ゲーム ウィンドウを前面に表示したままにしてください。
4.掃除準備画面でゲームが停止したら、「ラウンド開始」をクリックします。これにより、ゲーム内に表示されるアイテムが1回消費されます。プログラムは黄色の領域に到達しようとします。ラウンドの終わりに停止し、倍率ダイヤルはゲームによって処理されます。プログラムは停止画面を使用して、黄色に 2 回落ちたかどうかを推定します。表示されているのは画面上の解釈であり、境界付近に誤りがある可能性があります。

認識は画面幅の下部に合わせて行われ、異なるアスペクト比の完全な垂直ゲーム画面をサポートします。ゲーム画面のブロック、黒い境界線、トリミングを避ける。ウィンドウの上部にあるツールバーは、下部のコントロール領域の認識には影響しません。さまざまなデバイスとゲーム レイアウトをテストして確認する必要があります。キャンセルするには「停止」を押してください。携帯電話の前景が不明瞭である場合、ウィンドウの焦点が合っていない場合、画面が古い場合、または確認できない場合には、新しい入力は送信されません。

このバージョンは実験版です。携帯電話の実際のテストでは、黄色が 2 回ヒットし、ミスもありましたが、黄色は 2 回ヒットしました。遅延や映像速度は変動するため、毎回ヒットを保証するものではありません。さまざまな携帯電話は、独自の調整データを蓄積する必要があります。ウィンドウ キャプチャとスペースのショートカット キーは Thunderbolt でテストされており、完全に 2 ラウンドのイエロー判定があり、ミスもありました。他のシミュレータと他のショートカット キーはまだテストされていません。異なる解像度、アスペクト比、ゲームのバージョン、デバイスの遅延や速度が結果に影響を与える可能性があるため、観察しながら使用してください。

ソース コードとサードパーティのライセンス情報は、リリース パッケージに含まれています。
